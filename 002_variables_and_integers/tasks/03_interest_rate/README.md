# Инвестиции сложные проценты

Вклад в банке начисляет сложные проценты: каждый год сумма на счёте увеличивается на r процентов (целое число процентов, например 5 означает 5%). Вклад открыт на 2 года, проценты капитализируются ежегодно. Начальная сумма вклада задаётся в рублях (целое число). Хорошее решение перевести сумму в копейки.

С клавиатуры вводятся два целых числа: P (рубли) и r (процент). Выведите итоговую сумму в рублях и копейках в формате:

Пример ввода:

```
1000 5
```
Пример вывода:

```
final sum - 1102 rub, 50 kopeck
```
