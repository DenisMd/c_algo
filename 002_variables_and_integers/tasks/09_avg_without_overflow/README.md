# Среднее значение без переполнение

`Внимание это усложненная задача, с ней могут быть проблемы`

С клавиатуры вводится 2 целых числа. Вывести их среднее значение, если среднее значение дробное, то выведите целую часть(2.7 => 2)

Формула расчета
$$avg = \frac{a+b}{2}$$

<span style="color:red"> Не допустите переполнения при сложение a+b!!! </span>


Пример ввода:

```
2000000001 2000000001
```
Пример вывода:

```
avg = 2000000001
```

Подсказка
любое число можно представить как 
$$a = p_a*2 + q_a, \newline p_a - \text{целая часть при делении на 2} \newline 
q_a - \text{остаток при делении на 2}$$
