# Сумма арифмитической прогрессии

`Внимание здесь вам нужно самим вывести формулу! Если не получается, то загуглите. Циклы не использовать`

С клавиатуры вводится целое положительное число n.

Формула расчета
$$
S_n = 1+2+3...+n
$$

Пример (n=4)
$$
S_4 = 1+2+3+4 = 10
$$

Пример ввода:

```
100
```
Пример вывода:

```
5050
```
