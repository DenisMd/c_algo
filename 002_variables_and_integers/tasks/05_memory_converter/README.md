# Конвертер байт в гигабайты

С клавиатуры вводится целое число **total_bytes** — количество байт. Выведите, сколько это килобайт, мегабайт, гигабайт по формату:
`
GB gigabytes, MB megabytes, kB kilobytes
`
*Число может быть достаточно большим (поместится в 64-битный целый тип)..*

Пример ввода:

```
1234567890
```
Пример вывода:

```
1 GB, 153 MB, 384 KB, 722 bytes
```
* в 1 килобайт 1024 байт
* в 1 мегабайт 1024 килобайт
* в 1 гигабайте 1024 мегабайт
