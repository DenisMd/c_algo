# Конвертер секунд в время

С клавиатуры вводится целое число **total_seconds** — количество секунд. Выведите, сколько это часов, минут и секунд, по формату:
`
H hours, M minutes, S seconds
`
*(без проверок корректности, число секунд неотрицательное).*

Пример ввода:

```
3665
```
Пример вывода:

```
1 hours, 1 minutes, 5 seconds
```
* в 1 минуте 60 секунд
* в 1 часе 60 минут
