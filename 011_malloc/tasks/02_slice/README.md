# Срез массива (slice)

![](image.png)

Реализовать функцию, которая **выделяет** новый массив и копирует в него
элементы исходного с `from` по `to`, не включая `to` (полуинтервал
`[from, to)`) — аналог `a[from:to]` в Python:

```c
int *slice(const int *a, size_t n, size_t from, size_t to);
```

Например:

```
a = {10, 20, 30, 40, 50}
slice(a, 5, 1, 4)  ->  {20, 30, 40}
slice(a, 5, 0, 5)  ->  {10, 20, 30, 40, 50}
slice(a, 5, 2, 2)  ->  {}
```

### Требования

- Длина среза — `to - from`; исходный массив не меняем (он `const`).
- Память брать `malloc`, результат проверять на `NULL`. Освобождать в `main`
  через `free`.
- Копировать `memcpy` (`<string.h>`) или циклом — но ровно `to - from`
  элементов, не больше.
- Функция не доверяет вызывающему: при `from > to` или `to > n` вернуть `NULL`.
- Пустой срез (`from == to`) — вернуть `NULL`, ничего не выделяя.

### Формат ввода

```
N
a0 a1 ... a(N-1)
from to
```

Программа печатает срез в одну строку через пробел (пустая строка, если срез
пустой).

5
