# Непрерывное начисление процентов

В задаче 03 проценты капитализировались **раз в год** или **12 раз в год**. Чем чаще начисление, тем больше итоговая сумма (при той же номинальной ставке \(r\)). В пределе — **бесконечно частое** начисление, «непрерывная капитализация».

> Математика  
> Общая формула при \(n\) начислениях в год в течение \(t\) лет:  
> $$A_n = P \left(1 + \frac{r}{n}\right)^{nt}$$  
> При \(n \to \infty\):  
> $$\lim_{n\to\infty} A_n = P \cdot e^{rt}$$

### Задача

Со стандартного ввода: начальная сумма \(P\), годовая ставка \(r\) (в долях), срок \(t\) (лет).

Посчитать итоговую сумму для пяти случаев — **без циклов**:

| | Частота начисления |
|---|---|
| раз в год | \(n = 1\) |
| 12 раз в год | \(n = 12\) |
| 365 раз в год | \(n = 365\) |
| 1 000 000 раз в год | \(n = 10^6\) |
| непрерывно | \(Pe^{rt}\) |

Для дискретных случаев используйте общую формулу \(A_n\) выше.

Вывести шесть строк (подписи — как в таблице, последняя строка — разность между непрерывным случаем и случаем \(n = 10^6\)):

```
A1    - ...
A12   - ...
A365  - ...
A1e6  - ...
Acont - ...
Delta - ...
```
