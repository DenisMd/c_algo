# Сложные проценты

![percents](image.png)

Банк обещает «8% годовых». Это **номинальная** ставка: процент начисляется на уже накопленную сумму, а не только на первоначальный вклад. Чем дольше срок, тем сильнее расходится результат с простым линейным расчётом «каждый год +8% от начальной суммы».

> Экономический смысл  
> **Простые проценты:** каждый год добавляется одна и та же сумма \(P \cdot r\). За \(n\) лет: \(A_{simple} = P + P \cdot r \cdot n\).  
> **Сложные проценты:** процент капитализируется — в следующем году начисление идёт на уже выросшую сумму:  
> $$A = P \cdot (1 + r)^n$$  
> При ежемесячном начислении (12 раз в год) **эффективная годовая ставка** выше номинальной:  
> $$r_{eff} = \left(1 + \frac{r}{12}\right)^{12} - 1$$

Правило 72: при ставке 8% вклад примерно удвоится за \(72/8 \approx 9\) лет — это грубая оценка, а формула выше даёт точный ответ (в идеальной математике; в `double` — уже нет).

### Задача

Со стандартного ввода приходят три числа:

```
P   — начальная сумма (руб.)
r   — годовая номинальная ставка в долях (0.08 = 8%)
n   — срок в годах
```

Рассчитать и вывести:

1. **Сложные проценты (раз в год):** \(A = P \cdot (1 + r)^n\)
2. **Простые проценты (для сравнения):** \(A_{simple} = P \cdot (1 + r \cdot n)\)
3. **Эффективная годовая ставка** при ежемесячном начислении: \(r_{eff} = (1 + r/12)^{12} - 1\)

Формат вывода (именно так, с `%f` или `%e` — на ваш выбор, но все три строки должны быть):

```
Compound amount - <значение>
Simple amount   - <значение>
Effective rate  - <значение>
```

Использовать `double` и функцию `pow` из `<math.h>`.

### Подготовленные тесты

| Файл | P | r | n | Зачем |
|------|---|---|---|-------|
| `deposit.txt` | 100000 | 0.08 | 10 | Обычный вклад — всё выглядит разумно |
| `penny.txt` | 0.01 | 0.05 | 200 | Малая сумма, длинный срок — накопление с малым P |
| `hyper.txt` | 1000 | 2.0 | 700 | Гиперинфляция: \((1+r)^n\) улетает в `inf` |
| `tiny_rate.txt` | 1e6 | 1e-9 | 1e9 | Крошечная ставка, огромный срок — точность `pow` |
| `micro.txt` | 1e6 | 0.08 | 1e-6 | Срок меньше года — \((1+r)^n \approx 1 + rn\) |

Пример запуска:

```
gcc app.c -o a.out -lm
./a.out < deposit.txt
```

Все тесты разом (из папки задания, после сборки):

```
../../../utils/scripts/run_all.sh
```

Ожидаемый вывод для `deposit.txt` (математически; последние цифры в `double` могут чуть отличаться):

```
Compound amount - 215892.500000
Simple amount   - 180000.000000
Effective rate  - 0.083000
```

Для `hyper.txt` сложная сумма должна стать бесконечностью:

```
Compound amount - inf
Simple amount   - 1401000.000000
Effective rate  - 5.358600
```

(`Effective rate` при \(r = 2.0\) тоже огромна — посмотрите, что получится.)



| Явление | Где проявится |
|---------|----------------|
| Переполнение → `inf` | `hyper.txt`, большие \(r\) и \(n\) в `pow(1+r, n)` |
| Потеря значимости | `r_eff = pow(...) - 1.0` при очень малом \(r\) |
| Накопление ошибки в `pow` | `tiny_rate.txt`, `penny.txt` |
| Разный масштаб слагаемых | сравнение `Compound` и `Simple` на одних и тех же данных |
