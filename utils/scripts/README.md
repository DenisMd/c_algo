Задания раздела лежат в двух папках:

- `tasks/<NN_имя>/` — условие (`README.md`), заготовка (`app.c`) и тестовые входы (`*.txt`). **Здесь вы решаете.**
- `solved_tasks/<NN_имя>/` — эталонное решение (подсматривать после того, как решили сами).

## Как проверить своё решение

В каждой папке задания уже лежат тестовые входы `*.txt`. Решаете прямо в `tasks/<NN_имя>/`, затем компилируете и прогоняете все тесты одним скриптом.

Перейдите в папку задания и выполните:

```bash
cd tasks/01_is_prime          # ваша папка с заданием

gcc app.c -o a.out -lm        # скомпилировать решение (-lm нужен для math.h; лишним не будет)

../../../utils/scripts/run_all.sh
```

Скрипт [`utils/scripts/run_all.sh`](../utils/scripts/run_all.sh) найдёт в текущей папке `./a.out` и все `*.txt`, запустит программу на каждом входе и покажет вывод:

```
=== ./prime.txt ===
Enter integer N: 1

=== ./composite.txt ===
Enter integer N: 0
...
```

### Пояснения

- Запускать скрипт нужно **из папки задания** — он работает с `./a.out` и `./*.txt` в текущей директории.
- Флаг `-lm` подключает математическую библиотеку (`sqrt`, `pow`, `fabs`, `acos` …). Для заданий без `math.h` он не мешает, поэтому можно всегда собирать с ним.
- Один тест — один файл `*.txt` с данными для стандартного ввода. Свои тесты добавляйте, просто создав новый `*.txt` в папке задания.
- `a.out` в репозиторий не попадает (он в `.gitignore`).
