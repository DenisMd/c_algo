# Математическая индукция — решение

Задание: [`tasks/01_induction/README.md`](../../tasks/01_induction/README.md).

Схема одна и та же для всех трёх пунктов: сначала **база** (`n = 1`), затем **шаг**
(предполагаем истинность для `n = k` и доказываем для `n = k + 1`).

---

## 1. Сумма квадратов

Утверждение:

```
P(n):   1² + 2² + ... + n² = n(n+1)(2n+1) / 6
```

**База (n = 1).**

```
Слева:  1² = 1
Справа: 1·2·3 / 6 = 6 / 6 = 1
```

Совпадает — `P(1)` истинно.

**Шаг.** Пусть `P(k)` истинно:

```
1² + 2² + ... + k² = k(k+1)(2k+1) / 6
```

Добавим `(k+1)²` к обеим частям:

```
1² + ... + k² + (k+1)² = k(k+1)(2k+1)/6 + (k+1)²
```

Приводим правую часть к общему знаменателю и выносим `(k+1)`:

```
= (k+1)·[ k(2k+1) + 6(k+1) ] / 6
= (k+1)·[ 2k² + k + 6k + 6 ] / 6
= (k+1)·[ 2k² + 7k + 6 ] / 6
= (k+1)(k+2)(2k+3) / 6
```

А это в точности формула для `n = k + 1`:

```
(k+1)·((k+1)+1)·(2(k+1)+1) / 6 = (k+1)(k+2)(2k+3) / 6
```

Значит `P(k) ⟹ P(k+1)`. По индукции утверждение верно для всех `n ≥ 1`. ∎

## 2. 2ⁿ > n

Утверждение:

```
P(n):   2ⁿ > n,   n ≥ 1
```

**База (n = 1).**

```
2¹ = 2 > 1
```

Истинно.

**Шаг.** Пусть `2ᵏ > k`. Домножим обе части на `2`:

```
2ᵏ⁺¹ = 2·2ᵏ > 2k = k + k
```

Так как `k ≥ 1`, то `k ≥ 1` и `k + k ≥ k + 1`. Отсюда:

```
2ᵏ⁺¹ > k + k ≥ k + 1
```

то есть `2ᵏ⁺¹ > k + 1`. Значит `P(k) ⟹ P(k+1)`. По индукции `2ⁿ > n` для всех `n ≥ 1`. ∎

## 3. Сумма нечётных чисел

Утверждение:

```
P(n):   1 + 3 + 5 + ... + (2n − 1) = n²
```

**База (n = 1).**

```
Слева:  1
Справа: 1² = 1
```

Истинно.

**Шаг.** Пусть `P(k)` истинно:

```
1 + 3 + ... + (2k − 1) = k²
```

Следующее нечётное число — это `2(k+1) − 1 = 2k + 1`. Добавим его:

```
1 + 3 + ... + (2k − 1) + (2k + 1) = k² + (2k + 1) = k² + 2k + 1 = (k + 1)²
```

Получили формулу для `n = k + 1`. Значит `P(k) ⟹ P(k+1)`, и по индукции сумма
первых `n` нечётных чисел равна `n²` для всех `n ≥ 1`. ∎
