# Рекурсивный разворот числа

Реализовать **рекурсивную** функцию, которая разворачивает число задом наперёд:

```c
int reverse_number(....);
```

Сигнатуру придумайте сами. Подумайте, какие параметры нужны функции, чтобы разворот
можно было выразить рекурсивно (подсказка ниже).

Например:

```
reverse_number(1234) = 4321
reverse_number(5071) = 1705
reverse_number(7)    = 7
```

### Требования

- Реализация именно **рекурсивная**, без цикла.
- Придумать подходящую сигнатуру самим (скорее всего понадобится вспомогательная
  функция с дополнительным параметром-аккумулятором).
- Хвостовые нули «съедаются»: `reverse_number(5071) = 1705`, а `reverse_number(100) = 1`.

### Формат ввода

```
N
```

Программа читает число `N`, вызывает `reverse_number(N)` и печатает результат.
