# Математическая индукция

В этих задачах не нужно писать код, нужно по индукции на листочке доказать следущие утверждения.

### Как работает индукция

Чтобы доказать, что утверждение `P(n)` верно для всех натуральных `n`, достаточно:

1. **База** — проверить, что `P(1)` истинно.
2. **Шаг** — предположить, что `P(k)` истинно (предположение индукции), и вывести из
   этого, что тогда истинно и `P(k+1)`.

Если оба пункта выполнены, то по принципу индукции `P(n)` верно для всех `n ≥ 1`.

### Что доказать

**1. Сумма квадратов**

```
1² + 2² + 3² + ... + n² = n(n+1)(2n+1) / 6
```

**2. Экспонента растёт быстрее аргумента**

```
2ⁿ > n   для всех n ≥ 1
```

**3. Сумма нечётных чисел**

```
1 + 3 + 5 + ... + (2n − 1) = n²
```

### Требования

- Для каждого утверждения отдельно показать **базу** и **шаг** индукции.
- В шаге явно использовать предположение индукции (формулу для `n = k`) и
  алгебраически привести выражение к нужному виду для `n = k + 1`.
