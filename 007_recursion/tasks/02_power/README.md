# Рекурсивное возведение в степень

Реализовать **рекурсивную** функцию возведения в степень (простую, не быструю):

```c
long long power(int a, int n);
```

Функция вычисляет `a` в степени `n`. Реализация должна быть именно рекурсивной —
через сведение задачи `aⁿ` к меньшей задаче `aⁿ⁻¹`, **без цикла** и без `pow`.

### Требования

- Показатель `n ≥ 0` (натуральный или ноль). Отрицательные степени в этой задаче не
  рассматриваем — для целочисленного результата они не имеют смысла.
- База рекурсии: `n == 0` даёт `1` для любого `a`.
- Возвращаемый тип — `long long`, чтобы вместить большие значения (например `2³⁰`).

### Формат ввода

```
a n
```

Программа читает `a` и `n`, вызывает `power(a, n)` и печатает результат.

### Примеры

```
2 10
```

```
1024
```

---

```
5 0
```

```
1
```

---

```
-2 3
```

```
-8
```
