# Рекурсивный подсчёт цифр

Реализовать **рекурсивную** функцию, которая считает количество цифр в числе:

```c
int count_digits(int n);
```

Например:

```
count_digits(5071) = 4
count_digits(7)    = 1
count_digits(0)    = 1
```

### Требования

- Реализация именно **рекурсивная**, без цикла.
- Однозначные числа (включая `0`) содержат `1` цифру — это база рекурсии.
- Отрицательные числа: знак `-` цифрой не считается, `count_digits(-123) = 3`.

### Формат ввода

```
N
```

Программа читает число `N`, вызывает `count_digits(N)` и печатает результат.
