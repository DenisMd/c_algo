# Генератор цифр: деление в столбик на static-переменной

Реализовать функцию, которая при **каждом вызове** возвращает следующую десятичную цифру дроби `1/d`:

```c
int next_digit(int denom);
```

Первый вызов возвращает первую цифру после запятой, второй — вторую, и так далее. **Без массивов** — только одна `static` переменная, хранящая остаток между вызовами.

### Идея: деление в столбик

Так мы в школе делим уголком. Чтобы получить десятичные цифры `1/7`:

```
остаток = 1
шаг: остаток *= 10;  цифра = остаток / 7;  остаток %= 7;
```

```
1*10=10 -> 10/7=1, остаток 3
3*10=30 -> 30/7=4, остаток 2
2*10=20 -> 20/7=2, остаток 6
...            -> 1 4 2 8 5 7  (и снова 1 4 2 8 5 7 — период)
```

Ключевой момент: остаток нужно **помнить между вызовами** функции. Обычная локальная переменная обнулялась бы каждый раз. Поэтому используем `static` — она инициализируется один раз и сохраняет значение до следующего вызова.

### Формат ввода

```
d k
```

`d` — знаменатель дроби `1/d` (`d >= 2`, чтобы дробь была правильной: `0 < 1/d < 1`), `k` — сколько цифр вывести (`k >= 1`).

### Примеры

```
7 10
```

```
1/7 = 0.1428571428
```

---

```
3 5
```

```
1/3 = 0.33333
```

---

```
8 6
```

```
1/8 = 0.125000
```
