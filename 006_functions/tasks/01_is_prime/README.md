# Проверка на простоту

Реализовать функцию:

```c
int is_prime(int n);
```

Функция возвращает `1`, если число `n` — **простое**, и `0` в противном случае.

Число называется простым, если оно больше `1` и делится без остатка только на `1` и на само себя.

### Требования

- Числа `n <= 1` простыми не являются — вернуть `0`.
- Проверять делители нужно только **до `sqrt(n)`** включительно: если у числа есть делитель больше корня, то ему обязательно соответствует парный делитель меньше корня.

### Формат ввода

```
N
```

Программа читает число `N`, вызывает `is_prime(N)` и печатает результат.

### Примеры

```
7
```
