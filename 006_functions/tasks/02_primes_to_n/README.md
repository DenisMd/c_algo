# Простые числа до N

Дано `N`. Вывести все **простые** числа от `1` до `N` включительно, каждое на своей строке.

Нужно реализовать две функции:

```c
int is_prime(int n);
void print_prime_numbers_to_n(int n);
```

- `is_prime(n)` — возвращает `1`, если `n` простое, иначе `0` (проверять делители до `sqrt(n)`).
- `print_prime_numbers_to_n(n)` — перебирает числа от `1` до `n` и печатает те, для которых `is_prime` вернула `1`.

### Формат ввода

```
N
```
