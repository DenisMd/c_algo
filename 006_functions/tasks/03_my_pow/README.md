# Своя функция возведения в степень

Реализовать собственную функцию возведения в степень (замену `pow` из `math.h`):

```c
double my_pow(double base, int exp);
```

Функция вычисляет `base` в степени `exp`, используя цикл (умножение в цикле, без `pow`).

### Требования

- Положительный показатель: перемножить `base` сам на себя `exp` раз.
- `exp == 0`: результат `1` (для любого `base`).
- **Отрицательный показатель** — подводный камень: `base^(-exp) = 1 / base^(exp)`. Считаем степень по модулю показателя, затем берём обратную величину.

```
2^10  = 1024
5^0   = 1
2^-3  = 1 / 2^3 = 0.125
```

### Формат ввода

```
base exp
```
