# Число-палиндром

Дано число `N`. Определить, читается ли оно одинаково слева направо и справа налево. Вывести `1` или `0`.

При некорректном вводе вывести в `stderr` сообщение `Incorrect input!` и завершить программу с кодом `1`.

### Формат ввода

```
N
```

### Примеры

```
12321
```

```
1
```

```
12345
```

```
0
```
