# Расчёт налога по категории и вычетам

![](image.png)

На вход подаются:

- годовой доход (вещественное число),
- категория налогоплательщика (целое число):
  - `1` — наёмный работник,
  - `2` — самозанятый,
  - `3` — ИП на упрощёнке,
- количество несовершеннолетних детей (целое число).

При некорректном вводе вывести в `stderr` сообщение `Incorrect input!` и завершить программу с кодом `1`.

## Правила расчёта

### 1) Вычет на детей

- За каждого ребёнка налоговая база уменьшается на `2000`.
- База не может быть меньше нуля.
- Если исходный доход больше `80000`, вычет не применяется.

### 2) Налог по категории

#### Категория 1: наёмный работник

- доход `<= 10000` — `10%`;
- часть от `10001` до `50000` — `15%`;
- всё, что выше `50000` — `20%`.

#### Категория 2: самозанятый

- доход `<= 20000` — `5%`;
- если доход `> 20000` — `12%` со всей суммы.

#### Категория 3: ИП на упрощёнке

- доход `<= 100000` — фиксированный налог `6000`;
- иначе `6%` со всего дохода, но не менее `6000`.

## Вывод

Итоговый налог с точностью до двух знаков после запятой.

## Формат ввода

```
income category children
```

## Примеры

```
60000 1 2
```

```
2000.00
```

```
30000 2 3
```

```
2880.00
```

```
120000 3 1
```

```
7200.00
```
