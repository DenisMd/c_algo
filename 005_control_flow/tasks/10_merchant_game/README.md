# Торговец между городами

Проект: текстовая игра-торговля между 4 городами. Управление — через **event loop**

## Правила

Игрок перемещается между городами `1`–`4`, покупает и продаёт один товар. Цель — **максимизировать золото за 30 ходов**.

### Состояние

| Поле   | Описание              |
|--------|-----------------------|
| `city` | текущий город (1–4)   |
| `gold` | золото                |
| `cargo`| товар в трюме         |
| `day`  | номер хода (1–30)     |
| `debt` | долг по кредиту       |

Старт: город `1`, золото `100`, товар `0`, день `1`, долг `0`.

### Цены

Формула покупки/продажи:

```
buy  = 10 + city * 3 + (day % 5) * city
sell = buy - 3
```

### Действия (каждое действие = +1 день)

| Команда | Действие |
|---------|----------|
| `1`     | Купить товар (ввести количество) |
| `2`     | Продать товар (ввести количество) |
| `3`     | Переехать в другой город |
| `4`     | Взять кредит: `+100` золота, долг `+110` |
| `0`     | Выйти досрочно |

**Переезд** стоит `2 * abs(city_a - city_b)` золота.

В начале каждого дня с долгом списывается `10%` долга (округление вниз, минимум `1`).

Трюм вмещает не более `50` единиц товара.

### Интерфейс

```
=== День 12 | Город 2 | Золото: 145 | Товар: 30 | Долг: 0 ===
Цены сегодня:
  Город 1: покупка 15, продажа 12
  Город 2: покупка 20, продажа 17  <- вы здесь
  Город 3: покупка 25, продажа 22
  Город 4: покупка 30, продажа 27  <- выгодно везти!

[1] Купить  [2] Продать  [3] Переехать  [4] Взять кредит  [0] Выход
Ход: _
```

Подсказка «выгодно везти» — город с **максимальной ценой продажи** (если это не текущий город).

### Конец игры

После 30-го дня или выхода (`0`) вывести итог:

```
Итог: золото 230, долг 0, чистый капитал 230
```

Чистый капитал = `gold - debt`.
