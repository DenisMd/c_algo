# Совершенные числа

Дано `N`. Выписать все **совершенные** числа от `1` до `N` включительно.

Число совершенное, если оно равно сумме всех своих делителей кроме себя самого.

```
6 = 1+2+3
```

При некорректном вводе вывести в `stderr` сообщение `Incorrect input!` и завершить программу с кодом `1`.

Первые совершенные числа: `6`, `28`, `496`, `8128`. Следующее — уже `33 550 336`.

### Формат ввода

```
N
```

### Примеры

```
30
```

```
6
28
```

```
1000
```

```
6
28
496
```
