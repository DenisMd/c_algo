# Синусоида в терминале - практика

Вывести синусоиду в символах. Для каждой строки (`y` от `+1` до `-1`) пройти по всем столбцам (`x` от `0` до ширины) и поставить `*` там, где `sin(x * шаг) ≈ y`.

Добавить оси координат(опционально можете сделать стиль как захотите):

- **Ось Y** слева — символ `|`, подписи `1.0` (максимум) и `-1.0` (минимум).
- **Ось X** на уровне `y = 0` — символ `-`, под графиком — `+` и линия из `-`.
- Под осью X подписать `0` (минимум) и максимальное значение `(width - 1) * шаг`.

```
  1.0|      *****                           **
     |    **     *                        **
     |   *        **                     *
     |  *           *                  **
     | *             *                *
     |*---------------*--------------*--------
     |                 *            *
     |                  *          *
     |                   *        *
     |                    **    **
 -1.0|                      ****
     +----------------------------------------
      0                                    7.8
```

Два вложенных цикла: внешний по строкам (`y`), внутренний по столбцам (`x`). Используй `<math.h>`.

При некорректном вводе вывести в `stderr` сообщение `Incorrect input!` и завершить программу с кодом `1`.

## Параметры

- **Ширина** — задаётся с клавиатуры (количество столбцов).
- **Шаг по `x`** — `0.2` (константа).
- **Строки** — `y` от `1.0` до `-1.0` с шагом `0.2`.
- Сравнение `sin(x * шаг) ≈ y` — через `fabs` с допуском `y_step / 2`.

### Формат ввода

```
width
```

### Примеры

```
40
```
