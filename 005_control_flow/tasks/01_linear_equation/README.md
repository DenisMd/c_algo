# Решение линейного уравнения

Решить уравнение **ax + b = 0**.

С клавиатуры вводятся коэффициенты `a` и `b`. При некорректном вводе вывести в `stderr` сообщение `Incorrect input!` и завершить программу с кодом `1`.

Программа должна вывести:

- `Infinitely many solutions`
- `No solutions`
- `Solution: x = ...` с точностью **двух знаков** после запятой

### Примеры

```
2 -4
```

```
Solution: x = 2.00
```

```
0 0
```

```
Infinitely many solutions
```

```
0 5
```

```
No solutions
```
