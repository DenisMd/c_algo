# Проверка большинства


![majority](image.png)

Даны три булевы переменные `A`, `B`, `C` (в C — `bool` со значениями `false` или `true`).

С клавиатуры вводятся три числа `0` или `1`. Напишите **выражение**, которое возвращает `1`, если **хотя бы две** из трёх переменных равны `1`.

Запрещено использовать условные операторы и циклы. Разрешены только логические `&&`, `||`, `!`.

Вывести `1` или `0`.

Пример ввода:

```
1 1 0
```

Пример вывода:

```
1
```

Пример ввода:

```
1 0 0
```

Пример вывода:

```
0
```

Пример ввода:

```
0 1 1
```

Пример вывода:

```
1
```
