# Високосный год

![leap](image.png)

> Високосный год — это календарный год, включающий дополнительный день (29 февраля), который необходим для синхронизации календаря с астрономическим циклом вращения Земли вокруг Солнца (который составляет около 365,2422 дней)

Дано целое число `year` (год). Напишите выражение, которое возвращает `1`, если год **високосный** по григорианскому правилу, и `0` в противном случае.

Год високосный, если:

- делится на 4, **и**
- не делится на 100, **или** делится на 400

Пример ввода:

```
2004
```

Пример вывода:

```
1
```

Пример ввода:

```
1900
```

Пример вывода:

```
0
```

Пример ввода:

```
2000
```

Пример вывода:

```
1
```
