# Проверка транзакции на фрод

![fraud](image.png)

Банк получает свойства транзакции. Напишите **выражение**, которое возвращает `1`, если транзакция **подозрительная (фрод)**, и `0` в противном случае.

Запрещено использовать условные операторы и циклы.

### Ввод

Семь целых чисел:

```
amount hour is_foreign distance_km is_new_recipient is_card_present tx_last_hour
```

| Поле | Смысл |
|------|--------|
| `amount` | сумма, руб |
| `hour` | час суток, 0–23 |
| `is_foreign` | `1` — операция за рубежом |
| `distance_km` | расстояние от обычного места клиента, км |
| `is_new_recipient` | `1` — получатель впервые |
| `is_card_present` | `1` — карта при клиенте (не онлайн) |
| `tx_last_hour` | число транзакций за последний час |

### Правила фрода

Транзакция подозрительна, если выполняется **хотя бы одно** из условий:

1. **Кража карты:** сумма > 50 000 **и** операция за рубежом **и** карты нет при клиенте
2. **Захват аккаунта:** новый получатель **и** расстояние > 500 км **и** ночь (`hour < 6` или `hour >= 23`)
3. **Серия крупных списаний:** сумма > 200 000 **и** за последний час > 5 транзакций

### Вывод

`1` или `0`.

### Примеры

Обычная покупка:

```
5000 14 0 5 0 1 1
```

```
0
```

Кража карты за рубежом:

```
100000 14 1 800 0 0 1
```

```
1
```

Захват аккаунта ночью:

```
15000 2 0 700 1 1 1
```

```
1
```

Серия крупных списаний:

```
250000 12 0 10 0 1 6
```

```
1
```

Ночной банкомат рядом с домом:

```
3000 1 0 2 0 1 1
```

```
0
```
