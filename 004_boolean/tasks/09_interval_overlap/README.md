# Перекрытие отрезков

Даны два отрезка на числовой прямой: `[a, b]` и `[c, d]`, причём `a ≤ b` и `c ≤ d`.

Напишите выражение, которое возвращает `1`, если отрезки **имеют хотя бы одну общую точку** (включая касание по границе), и `0` в противном случае.

### Ввод

Четыре числа:

```
a b c d
```

### Вывод

`1` или `0`.

### Примеры

```
1 5 3 7
```

```
1
```

```
1 2 4 5
```

```
0
```

Касание по границе:

```
1 3 3 5
```

```
1
```
