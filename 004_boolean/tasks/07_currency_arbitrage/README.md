# Арбитраж валют

![currency](image.png)

Даны три курса обмена:

- `rate_ab` — сколько единиц валюты B за 1 единицу A
- `rate_bc` — сколько единиц валюты C за 1 единицу B
- `rate_ca` — сколько единиц валюты A за 1 единицу C

Напишите выражение, которое возвращает `1`, если кольцевой обмен `A → B → C → A` даёт **прибыль** (в итоге получается больше одной единицы A), и `0` в противном случае.

### Ввод

Три числа:

```
rate_ab rate_bc rate_ca
```

### Вывод

`1` или `0`.

### Примеры

```
1.1 1.1 1.1
```

```
1
```

```
0.9 0.9 0.9
```

```
0
```

```
1.05 1.05 0.95
```

```
1
```
