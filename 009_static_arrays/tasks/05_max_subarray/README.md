# Максимальная сумма подотрезка (Кадане)

В массиве `int a[]` (числа могут быть отрицательными) найти непрерывный
**непустой** подотрезок с максимальной суммой и вернуть эту сумму:

```c
long max_subarray(const int a[], size_t n);
```

Например:

```
{-2, 1, -3, 4, -1, 2, 1, -5, 4}  ->  6      // подотрезок {4, -1, 2, 1}
{1, 2, 3, 4, 5}                  ->  15     // весь массив
{-3, -1, -2}                     ->  -1     // все отрицательные: берём один максимальный
```

### Требования

- Алгоритм Кадане за один проход: ведём `cur` — лучшую сумму подотрезка,
  оканчивающегося на текущем элементе. Если `cur` стал `<= 0`, тянуть его дальше
  невыгодно — начинаем новый подотрезок с текущего элемента.
- Максимум инициализировать значением `a[0]`, **не нулём**: иначе для массива из
  одних отрицательных чисел ответ был бы неверным (пустой подотрезок не в счёт).
- Сумму копить в `long`: сумма многих `int` может не влезть в `int`.
- Подотрезок непустой, поэтому `N >= 1`.

### Формат ввода

```
N
a0 a1 ... a(N-1)
```

Программа читает `N` и `N` чисел и печатает максимальную сумму подотрезка.

### Примеры

```
9
-2 1 -3 4 -1 2 1 -5 4
```

```
6
```

---

```
3
-3 -1 -2
```

```
-1
```
