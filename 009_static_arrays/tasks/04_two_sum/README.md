# Two-sum

В массиве `int a[]` найти пару **разных** индексов `(i, j)`, для которых
`a[i] + a[j] == target`:

```c
bool two_sum(const int a[], size_t n, int target, size_t *i, size_t *j);
```

Например:

```
a = {2, 7, 11, 15}, target = 9   ->  (0, 1)   // 2 + 7 = 9
a = {3, 2, 4},      target = 6   ->  (1, 2)   // 2 + 4 = 6
a = {1, 2, 3},      target = 100 ->  пары нет
```

### Требования

- Два **разных** индекса: `i != j`, один и тот же элемент дважды не берём
  (перебираем пары `j > i`).
- Если пар несколько — вернуть **первую** (наименьший `i`, при равенстве — `j`).
- Функция возвращает `true` и кладёт индексы в `*i`, `*j`, если пара есть;
  иначе `false`.

### Формат ввода

```
N
a0 a1 ... a(N-1)
target
```

Программа читает `N`, `N` чисел и `target`, затем печатает два индекса через
пробел, либо строку `нет пары`.

### Примеры

```
4
2 7 11 15
9
```

```
0 1
```

---

```
3
1 2 3
100
```

```
нет пары
```
