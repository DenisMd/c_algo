# Гистограмма цифр

Дан массив `int a[]` неотрицательных чисел. Построить `int count[10]`, где
`count[d]` — сколько раз цифра `d` встретилась во всех числах суммарно:

```c
void digit_histogram(const int a[], size_t n, int count[10]);
```

Например:

```
{11, 22, 13}  ->  count[1]=3, count[2]=2, count[3]=1, остальные 0
{5, 55, 555}  ->  count[5]=6
{0}           ->  count[0]=1
```

### Требования

- Число `0` содержит одну цифру `0`. Не потеряй этот случай: цикл
  `while (x > 0)` для нуля не выполнится ни разу.
- `count` обнуляется внутри функции; все входные числа неотрицательные.

### Формат ввода

```
N
a0 a1 ... a(N-1)
```

Программа читает `N` и `N` неотрицательных чисел и печатает 10 строк вида
`d: count[d]`.
