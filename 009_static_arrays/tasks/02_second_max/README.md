# Второй по величине

Найти **второй максимум** массива за **один проход**:

```c
bool second_max(const int a[], size_t n, int *second);
```

Второй максимум — это наибольшее значение, **строго меньшее** максимума.
Дубликаты максимума за второе место не считаются:

```
{5, 5, 3}        ->  3
{1, 2, 3, 4, 5}  ->  4
{7, 7, 7}        ->  второго максимума нет
```

### Требования

- Один проход по массиву, без дополнительной памяти (без сортировки).
- Функция возвращает `true` и кладёт ответ в `*second`, если второй максимум есть;
  возвращает `false`, если его нет (все элементы равны или элементов меньше двух).

### Формат ввода

```
N
a0 a1 ... a(N-1)
```

Программа читает `N` и `N` чисел и печатает второй максимум, либо строку
`нет второго максимума`.

### Примеры

```
3
5 5 3
```

```
3
```

---

```
3
7 7 7
```

```
нет второго максимума
```
